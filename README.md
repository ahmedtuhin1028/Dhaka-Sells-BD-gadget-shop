# Dhaka Sells BD Gadget Shop

A modern, full-stack, Next.js 14 e-commerce platform built for the Bangladesh market.

## 📋 Requirements
- Node.js 18.x or newer
- PostgreSQL database (Local, Supabase, or Neon)
- Cloudinary or AWS S3 account (for image hosting)
- Payment Gateway Merchant Accounts (SSLCommerz, bKash) (Optional for dev)
